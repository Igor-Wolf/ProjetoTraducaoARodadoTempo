# Projeto de Tradução Comunitária — A Roda do Tempo

## Sobre o Projeto

Este projeto tem como objetivo realizar a tradução voluntária de conteúdos relacionados à saga **A Roda do Tempo** (*The Wheel of Time*), escrita por Robert Jordan e concluída por Brandon Sanderson.

A iniciativa busca traduzir por meio de IA materiais de forma organizada, consistente e acessível para a comunidade BR.

Editora Intrinseca afirmou que não pussi os direitos dos livro 10 em diante e não há planos de adquirí-los no momento. Deste modo, o projeto visa finalizar a tradução para os volumes que não foram publicados. 

O projeto é uma tradução sem fins lucrativos e possui o intuito de trazer cultura para a população. Não detenho os direitos autorais, está é uma tradução de fã para fã.

## Objetivos

- Traduzir conteúdos selecionados.
- Revisar traduções de forma colaborativa.
- Disponibilizar materiais em português para fãs da saga.

## Estrutura de Trabalho

### 1. Tradução
Será realizada uma análise por modelo de IA local de um ebook em inglês. Feito isso os arquvios em .json serão remontados de modo a manter a estrutura.

### 2. Revisão

A revisão será realizada pessoalmente, quem se interessar poderá ler o arquivo e sugerir mudanças no .json para melhor fluidez no livro.




## Licença e Direitos Autorais

Este projeto é conduzido por fãs e tem finalidade educacional e comunitária. Os direitos sobre a obra original pertencem aos respectivos autores e detentores legais.
